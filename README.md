> ⚠️ **Snake setup:** To activate the snake animation, create a GitHub Action in your profile repo. See setup instructions below.

<details>
<summary>🔧 Snake Action Setup (click to expand)</summary>

Create `.github/workflows/snake.yml` in your profile repo (`ReejanOpYT/ReejanOpYT`):

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
